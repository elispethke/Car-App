# 🚘 BMW Car Detail Screen - React Native

This is a **React Native** car detail screen designed for car rental or sales apps. The interface is modern, responsive, and includes interactive features such as an image carousel, favorite button, pricing table, and cancellation policy.

## ✨ Features

- 📸 Horizontal image carousel with smooth animation
- 📍 Detailed vehicle information (model, color, transmission type, year, etc.)
- ❤️ "Favorite" button with reactive state
- ⬇️ Download button (placeholder for future implementation)
- 📅 Rental pricing table by period
- 👤 Owner section with ratings and number of available cars
- 🧾 Cancellation policy
- 📲 Fixed "Book Now" button at the bottom
- 📱 Responsive design for multiple screen sizes
